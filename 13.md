# Phase 14: Jenkins Pipelines (Pipeline as Code)

## Objective

Create and execute a Jenkins Pipeline using **Pipeline as Code** with a Declarative Pipeline. Configure multiple stages to automate the Build, Test, and Deploy workflow.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Job Type | Pipeline |
| Pipeline Type | Declarative Pipeline |

---

# Step 1: Create a Pipeline Job

Navigate to:

```
Dashboard
→ New Item
```

Enter the job name:

```
pipeline-demo
```

Select:

```
Pipeline
```

Click:

```
OK
```

---

# Step 2: Configure the Pipeline

Navigate to:

```
Pipeline
```

Definition:

```
Pipeline Script
```

Enter the following Declarative Pipeline script:

```groovy
pipeline {
    agent any

    stages {

        stage('Build') {
            steps {
                echo 'Build Stage'
            }
        }

        stage('Test') {
            steps {
                echo 'Test Stage'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploy Stage'
            }
        }
    }
}
```

Click:

```
Save
```

---

# Step 3: Execute the Pipeline

Open the pipeline job.

Click:

```
Build Now
```

Jenkins starts executing each stage sequentially.

---

# Step 4: Verify Pipeline Execution

```
