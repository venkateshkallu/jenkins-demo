# Phase 13: Upstream & Downstream Jobs

## Objective

Configure Jenkins Upstream and Downstream Jobs to automate job execution by triggering one job after another upon successful completion.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Job Type | Freestyle Project |

---

# Step 1: Create Job 1

Navigate to:

```
Dashboard
→ New Item
```

Enter:

```
job1
```

Select:

```
Freestyle Project
```

Click:

```
OK
```

### Configure Build Step

Navigate to:

```
Build
→ Add Build Step
→ Execute Shell
```

Enter:

```bash
echo "Executing Job 1"
```

Click:

```
Save
```

# Step 3: Configure Upstream Job

Open:

```
job1
→ Configure
```

Navigate to:

```
Post Build Actions
```

Click:

```
Add Post-build Action
```

Select:

```
Build other projects
```

Project to build:

```
job2
```

Trigger Condition:

```
Trigger only if build is stable
```

Click:

```
Save
```

---

# Step 4: Trigger the Pipeline

Navigate to:

```
job1
```

Click:

```
Build Now
```

---

# Step 5: Verify Job Chaining

Observe the Build Queue.

Expected sequence:

```
job1
        │
        ▼
job2
```

After `job1` completes successfully, Jenkins automatically triggers `job2`.
