# Phase 16: Parallel Pipeline Execution

## Objective

Create a Jenkins Declarative Pipeline that executes multiple stages in parallel, allowing independent tasks to run simultaneously and reducing the overall pipeline execution time.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Job Type | Pipeline |
| Pipeline Type | Declarative Pipeline |

---

# Step 1: Create a Pipeline Job

Navigate to:

```
Dashboard
→ New Item
```

Enter the job name:

```
parallel-pipeline
```

Select:

```
Pipeline
```

Click:

```
OK
```

---

# Step 2: Configure the Pipeline

Navigate to:

```
Pipeline
```

Definition:

```
Pipeline Script
```

Enter the following Declarative Pipeline script:

```groovy
pipeline {
    agent any

    stages {

        stage('Parallel Execution') {

            parallel {

                stage('Linux') {
                    steps {
                        echo 'Linux Tests'
                    }
                }

                stage('Windows') {
                    steps {
                        echo 'Windows Tests'
                    }
                }

            }

        }

    }
}
```

Click:

```
Save
```

---

# Step 3: Execute the Pipeline

Open the pipeline job.

Click:

```
Build Now
```

Jenkins starts the pipeline and executes both **Linux** and **Windows** stages simultaneously.

---
