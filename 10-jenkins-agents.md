# Phase 11: Jenkins Agents (Distributed Builds)

## Objective

Configure a Jenkins Agent (Node) to enable distributed builds, allowing Jenkins Controller to delegate build execution to a remote agent.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Java Version | OpenJDK 17 |
| Connection Method | WebSocket |
| Controller URL | http://localhost:8080 |
| Agent Name | agent1 |

---

# Step 1: Enable Agent Port

Navigate to:

```
Manage Jenkins
→ Security
```

Enable:

```
TCP Port for Inbound Agents
```

Select:

```
Fixed
```

Port:

```
50000
```

Click **Save**.

---

# Step 2: Create Agent Node

Navigate to:

```
Manage Jenkins
→ Nodes
→ New Node
```

Node Name:

```
agent1
```

Select:

```
Permanent Agent
```

Click **Create**.

---

# Step 3: Configure Agent

| Setting | Value |
|----------|-------|
| Name | agent1 |
| Remote Root Directory | /home/dell/jenkinsagent |
| Number of Executors | 2 |
| Labels | agent1 |
| Usage | Use this node as much as possible |
| Launch Method | Launch agent by connecting it to the controller |

Save the configuration.

---

# Step 4: Create Agent Working Directory

```bash
mkdir -p ~/jenkinsagent
cd ~/jenkinsagent
```

---

# Step 5: Download Jenkins Agent

```bash
curl -sO http://localhost:8080/jnlpJars/agent.jar
```

Verify:

```bash
ls
```

Output:

```
agent.jar
```

---

# Step 6: Connect Agent

Execute the command generated by Jenkins.

```bash
java -jar agent.jar \
-url http://localhost:8080/ \
-secret <SECRET_KEY> \
-name agent1 \
-webSocket \
-workDir "/home/dell/jenkinsagent"
```

---

# Step 7: Verify Agent Connection

Successful connection output:

```
INFO: Using /home/dell/jenkinsagent/remoting as a remoting work directory

INFO: Setting up agent: agent1

INFO: Using Remoting version: 3327.v868139a_d00e0

INFO: WebSocket connection open
```

Node status:

```
Online
```

---

# Step 8: Run Job on Agent

Open an existing Jenkins Job.

Navigate to:

```
General
```

Enable:

```
Restrict where this project can be run
```

Specify Label:

```
agent1
```

Save.

Run:

```
Build Now
```

Verify in Console Output:

```
Running on agent1
```

---

# Challenges Faced

## Issue 1

Error:

```
bash: your-secret: No such file or directory
```

### Cause

The placeholder

```
<your-secret>
```

was copied directly.

Bash interpreted `<` as input redirection.

### Resolution

Use the actual secret generated by Jenkins without angle brackets.

Example:

```bash
-secret c7ac740926e351d0d4aa3b8b8a66a8378616b6d3489a826ec957ae8a4d85047d
```

---

## Issue 2

Error:

```
java.nio.file.AccessDeniedException:
/home/ubuntu
```

### Cause

The Remote Root Directory was configured as:

```
/home/ubuntu/jenkins
```

while the logged-in user was:

```
dell
```

The user did not have permission to access `/home/ubuntu`.

### Resolution

Changed Remote Root Directory to:

```
/home/dell/jenkinsagent
```

Created the directory:

```bash
mkdir -p /home/dell/jenkinsagent
```

Agent connected successfully.

---

# Outcome

Successfully configured a Jenkins Agent and established a WebSocket connection between the Jenkins Controller and the Agent.

The distributed build environment is ready for executing Jenkins jobs on the agent node instead of the built-in controller.
