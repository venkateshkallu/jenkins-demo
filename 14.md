# Phase 15: Jenkinsfile from GitHub (Pipeline from SCM)

## Objective

Configure a Jenkins Pipeline to retrieve the pipeline definition (`Jenkinsfile`) directly from a GitHub repository using **Pipeline Script from SCM**. Execute the pipeline and verify successful integration between Jenkins and GitHub.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Source Code Management | Git |
| Repository Hosting | GitHub |
| Pipeline Type | Pipeline Script from SCM |

---

# Step 1: Create a Jenkinsfile

Create a file named:

```
Jenkinsfile
```

Add the following Declarative Pipeline code:

```groovy
pipeline {
    agent any

    stages {

        stage('Checkout') {
            steps {
                echo 'Checking out source code...'
            }
        }

        stage('Build') {
            steps {
                echo 'Building application...'
            }
        }

        stage('Test') {
            steps {
                echo 'Running tests...'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying application...'
            }
        }
    }
}
```

Save the file.

---

# Step 2: Push Jenkinsfile to GitHub

Initialize the Git repository (if not already initialized):

```bash
git init
```

Add the Jenkinsfile:

```bash
git add Jenkinsfile
```

Commit the changes:

```bash
git commit -m "Add Jenkinsfile"
```

Add the remote repository:

```bash
git remote add origin https://github.com/<username>/<repository>.git
```

Push the code:

```bash
git push -u origin main
```

Verify that the `Jenkinsfile` is available in the GitHub repository.

---

# Step 3: Create a Pipeline Job

Navigate to:

```
Dashboard
→ New Item
```

Enter the job name:

```
pipeline-from-github
```

Select:

```
Pipeline
```

Click:

```
OK
```

---

# Step 4: Configure Pipeline from SCM

Navigate to:

```
Pipeline
```

Definition:

```
Pipeline script from SCM
```

SCM:

```
Git
```

Repository URL:

```
https://github.com/<username>/<repository>.git
```

Branch Specifier:

```
*/main
```

Script Path:

```
Jenkinsfile
```

Click:

```
Save
```

---

# Step 5: Execute the Pipeline

Open the pipeline job.

Click:

```
Build Now
```

Jenkins automatically performs the following:

1. Connects to the GitHub repository.
2. Clones the repository.
3. Reads the `Jenkinsfile`.
4. Executes the pipeline stages.
5. Displays the build status.

---

# Pipeline Workflow

```
             GitHub Repository
                    │
                    ▼
        Fetch Jenkinsfile (SCM)
                    │
                    ▼
             Checkout Stage
                    │
                    ▼
              Build Stage
                    │
                    ▼
               Test Stage
                    │
                    ▼
             Deploy Stage
                    │
                    ▼
               Build Success
```
