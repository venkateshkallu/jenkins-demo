# Phase 17: Jenkins Maintenance (Restart Jenkins)

## Objective

Perform Jenkins maintenance by restarting the Jenkins server using both **Safe Restart** and **Immediate Restart** methods. Understand the difference between the two restart options and verify that Jenkins resumes normal operation after restarting.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Access Method | Web Browser |
| Jenkins URL | http://localhost:8080 |

---

# Safe Restart

A **Safe Restart** allows Jenkins to wait for all currently running builds to complete before restarting the server. No new builds are accepted during this period.

## Step 1: Perform Safe Restart

Open a web browser and navigate to:

```
http://localhost:8080/safeRestart
```

Alternatively, select:

```
Manage Jenkins
→ Safe Restart
```

*(Available depending on the installed plugins and Jenkins version.)*

Wait until all running jobs complete.

Jenkins will automatically restart after the running builds finish.

---

# Immediate Restart

An **Immediate Restart** stops Jenkins immediately without waiting for running jobs to complete. Any running builds may be interrupted.

## Step 2: Perform Immediate Restart

Open a web browser and navigate to:

```
http://localhost:8080/restart
```

Confirm the restart if prompted.

Wait for Jenkins to restart.

---

# Step 3: Verify Jenkins Status

After restarting, open:

```
http://localhost:8080
```

Verify:

- Jenkins Dashboard loads successfully.
- All configured jobs are available.
- Build history is preserved.
- Installed plugins are loaded correctly.
- Connected agents (if configured) reconnect successfully.

---

# Verification

- Successfully performed a Safe Restart.
- Successfully performed an Immediate Restart.
- Verified that Jenkins restarted without configuration loss.
- Confirmed that jobs and build history remained intact after the restart.

---

# Safe Restart vs Immediate Restart

| Feature | Safe Restart | Immediate Restart |
|---------|--------------|-------------------|
| Running Jobs | Waits for completion | Stops immediately |
| New Builds | Not accepted | Not accepted |
| Build Interruption | No | Yes |
| Recommended for Production | Yes | No (except emergencies) |
