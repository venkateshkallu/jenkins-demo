# Phase 9: Apache Tomcat Installation and Configuration

## Create Working Directory

```bash
mkdir -p ~/tomcat-lab
cd ~/tomcat-lab
```

## Install Apache Tomcat

```bash
sudo apt update
sudo apt install tomcat10 -y
```

## Verify Tomcat Package Status

```bash
dpkg -l | grep tomcat
```

Expected:

```text
ii  tomcat10
ii  tomcat10-common
ii  libtomcat10-java
```

---
## Locate Tomcat Configuration Files

### Find Server Configuration

```bash
sudo find / -name server.xml 2>/dev/null | grep tomcat
```

Output:

```text
/usr/share/tomcat10/etc/server.xml
```

---

## Configure Tomcat Port

### Open Server Configuration

```bash
sudo nano /usr/share/tomcat10/etc/server.xml
```

### Search for Connector Port

Find:

```xml
<Connector port="8080"
```

### Change Port

Update:

```xml
<Connector port="8081"
```

### Save Configuration

```text
CTRL + O
ENTER
CTRL + X
```

---

## Start Tomcat Service

### Restart Tomcat

```bash
sudo systemctl restart tomcat10
```

### Verify Service Status

```bash
sudo systemctl status tomcat10
```

Expected:

```text
Active: active (running)
```

### Verify Listening Port

```bash
ss -tulpn | grep 8081
```

Expected:

```text
http-nio-8081
```

---

## Configure Tomcat Manager User

### Open User Configuration File

```bash
sudo nano /etc/tomcat10/tomcat-users.xml
```

### Add Manager Roles and User

Insert before:

```xml
</tomcat-users>
```

Add:

```xml
<role rolename="manager-gui"/>
<role rolename="manager-script"/>

<user
username="deployer"
password="Password123"
roles="manager-gui,manager-script"/>
```

### Save Configuration

```text
CTRL + O
ENTER
CTRL + X
```

---

## Apply Configuration Changes

```bash
sudo systemctl restart tomcat10
```

## Troubleshoot Failed Installation



During installation, Tomcat package configuration failed because the required Tomcat group and user were not created automatically.



Error:



```text

chown: invalid group: root:tomcat

```



### Create Tomcat Group



```bash

sudo groupadd tomcat

```



### Create Tomcat User



```bash

sudo useradd \

-r \

-g tomcat \

-d /usr/share/tomcat10 \

-s /usr/sbin/nologin \

tomcat

```



### Complete Package Configuration



```bash

sudo dpkg --configure -a

```



### Verify Package Status



```bash

dpkg -l | grep tomcat

```



Expected:



```text

ii  tomcat10

ii  tomcat10-common

ii  libtomcat10-java

```
