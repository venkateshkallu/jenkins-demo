# Phase 12: Jenkins Backup & Recovery

## Objective

Configure Jenkins Backup & Recovery by installing a backup plugin, creating automated backups of Jenkins configuration, and verifying the generated backup archive.

---

## Environment

| Component | Details |
|-----------|---------|
| Operating System | Ubuntu Linux |
| Jenkins Version | 2.528.3 |
| Backup Plugin | ThinBackup Plugin *(or the plugin used in your setup)* |
| Backup Location | `/home/dell/jenkins-backup` |

---

# Step 1: Install Backup Plugin

Navigate to:

```
Manage Jenkins
→ Plugins
→ Available Plugins
```

Search for:

```
ThinBackup
```

Select:

```
ThinBackup Plugin
```

Click:

```
Install
```

Restart Jenkins if prompted.

---

# Step 2: Configure Backup

Navigate to:

```
Manage Jenkins
→ ThinBackup
→ Settings
```

Configure the following:

| Setting | Value |
|----------|-------|
| Backup Directory | `/home/dell/jenkins-backup` |
| Backup Schedule | Manual |
| Backup Builds | Optional |
| Backup Archive | Enabled |
| Compression | ZIP Format |

Click:

```
Save
```

---

# Step 3: Create Backup Directory

Create the backup directory on the Jenkins server.

```bash
mkdir -p ~/jenkins-backup
```

Verify:

```bash
ls -ld ~/jenkins-backup
```

---

# Step 4: Run Jenkins Backup

Navigate to:

```
Manage Jenkins
→ ThinBackup
→ Backup Now
```

Wait for the backup process to complete successfully.

---

# Step 5: Verify Backup Archive

Navigate to the backup directory.

```bash
cd ~/jenkins-backup
```

List the generated backup files.

```bash
ls -lh
```

Expected output:

```
backup-YYYY-MM-DD-HH-MM.zip
```

Verify the archive exists and contains the Jenkins configuration files.

---

# Recovery Process

If recovery is required:

Navigate to:

```
Manage Jenkins
→ ThinBackup
→ Restore
```

Select the required backup archive and restore the Jenkins configuration.

Restart Jenkins after the restore process completes.

---

# Verification

- Backup completed successfully.
- Backup archive created in the configured directory.
- Jenkins configuration files successfully stored.
- Backup archive available for future recovery.
